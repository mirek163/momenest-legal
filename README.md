česky a anglicky. Adresa, na kterou odkazuje Google Play, aplikace samotná
a přihlašovací obrazovka Google.

## Co tenhle repozitář je a co není

**Jsou to dva vygenerované soubory, nic víc.** Zdroj textu žije v soukromém
repozitáři aplikace (`src/i18n/locales/<jazyk>/legal.json`) a stránky z něj staví
`npm run legal:pages`. Aplikace i web tak ukazují stejná slova a nemůžou se
rozejít.

**Needitujte HTML tady.** Změna se dělá v aplikaci, znovu se vygeneruje a sem se
jen zkopíruje výsledek — jinak se příští generování přepíše.
